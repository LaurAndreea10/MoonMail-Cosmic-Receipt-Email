# MoonMail — Cosmic Receipt Email 🌙📧

An interactive cosmic receipt studio created for the **August 2026 CodePen Challenge: Email Receipts**.

MoonMail turns a standard transactional receipt into a small interstellar product experience: editable order data, responsive receipt previews, live delivery telemetry, multiple visual themes, export tools, local receipt history, bilingual UI, and a built-in arcade mini-game.

## Project concept

Most receipts are purely functional. MoonMail explores how a receipt can still communicate brand personality without losing its transactional purpose. The interface combines a believable order summary with fictional interstellar logistics, loyalty rewards, live telemetry, and playful interaction.

The result is both a **receipt design experiment** and a **small front-end application**.

## Main experience

### Receipt Preview
See the current order as a polished transactional receipt and switch between desktop, mobile, print, and inbox presentations.

### Live Builder
Edit order details and products while the receipt updates immediately.

### Delivery Telemetry
Track a fictional MoonMail shipment across its route and simulate progress all the way to delivery.

### Export & Save
Save versions locally or export the receipt for sharing and presentation.

### MoonMail Arcade
A small bonus game lets you pilot the delivery craft, collect cargo, and avoid meteors.

## GitHub Pages

The repository includes a GitHub Actions workflow in `.github/workflows/pages.yml` that publishes the static site from the `main` branch.

If GitHub Pages has not previously been enabled for this repository, open **Settings → Pages** and set the build source to **GitHub Actions**. Future pushes to `main` will then deploy automatically.
